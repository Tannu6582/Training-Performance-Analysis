# Training-Performance-Analysis
This project focuses on analyzing employee training performance using an interactive Dashboard. The dashboard helps organizations evaluate the effectiveness of training programs by examining training hours, costs, completion status, scores, feedback, and certification outcomes.

Key Insights from Dashboard
# Training Efficiency
Leadership & Conflict Management received the highest training focus
Negotiation Skills are underutilized → potential skill gap

# Completion Analysis
Only 43% training completed
Significant portion (33%) still incomplete → needs attention

# Performance Outcomes
Financial Modelling shows highest performance scores
Indicates strong ROI for technical training

# Feedback Trends
Majority of feedback is average → training quality can improve

# Certification Gap
Only 20% employees certified
Indicates low conversion from training → certification
